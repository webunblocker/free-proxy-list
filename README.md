# Socks5Proxies Free Proxy List

Snapshot of public proxy endpoints that passed Socks5Proxies.com's own latest check, refreshed every 6 hours.

> Latest snapshot: **240** verified-working proxies with metadata for **1** known countries at **2026-10-31T12:28:32.327Z (UTC)**.
> **239** endpoints have unknown location metadata (ZZ); no country is invented for them.

Only endpoints with a successful own check in the two hours before collection are included.
This is a timestamped result, not a guarantee that an endpoint still works. Re-check before use.
Failed, never-checked and stale rows are excluded even when that makes the snapshot small or empty.
The live site's tracked inventory and country facets deliberately use a broader, clearly labelled scope.

## Why this repo exists

- GitHub is the distribution channel for scheduled snapshots.
- The live site is the better product surface for filtering, exports, and validation.
- If you came here from search, use the live site when you need fresher data than the GitHub snapshot.

## Notes

- This repository refreshes every 6 hours. The main site updates more frequently.
- Public proxies have high churn. Re-check targets before production usage; never send credentials through them.
- JSON and CSV preserve `last_checked` and `health_score`. HTTPS transport checks do not measure anonymity; reported labels are not privacy guarantees.
- A successful empty snapshot is published as empty. A failed or incomplete collection exits nonzero and does not refresh the prior snapshot's timestamp.
- Use the live list, Bulk Checker, and API docs for fresher filtering and validation workflows.
